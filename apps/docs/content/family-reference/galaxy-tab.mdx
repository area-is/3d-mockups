`<GalaxyTab>` and `<GalaxyTabMockup>` render the Samsung Galaxy Tab S11 family
at true relative sizes - the 11" S11 and the 14.6" S11 Ultra. Each gets its
real hardware: the protruding camera rings and flash floating straight on the
back panel (two rings on the Ultra, one on the S11), the volume rocker and
power key on the long edge, the magnetic S Pen side-mount, the keyboard pogo
column, milled speaker slots near all four corners, USB-C on the edge adjacent
to the camera corner, and the SAMSUNG wordmark set for the landscape hold - so
it lies along the edge in portrait, exactly like the print on the hardware.
The Ultra adds the front camera's U-shaped display notch, which rides the right
edge in portrait and the top center in landscape, just like the physical panel.

## Props

Beyond the [shared screen props](/docs/screen-content) and, on the mockup, the
[shared mockup props](/docs/api):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'tabs11' \| 'tabs11ultra'` | `'tabs11'` | Tab S11 (single camera ring) or Tab S11 Ultra (dual rings, 14.6" panel with the U-shaped notch). |
| `orientation` | `'portrait' \| 'landscape'` | `'portrait'` | Landscape lays the tablet on its side and swaps the virtual display with upright content. |
| `statusBar` | `boolean \| StatusBarOption` | `false` | Draw the system status bar across the top of the screen. `true` gives the platform's defaults - One UI's tablet bar, with the clock at the leading inset and the meters at the trailing one; an object sets the clock, the meters and the ink (`{{ time: '14:05', battery: 0.42, batteryPercent: true, color: '#1c1c1e' }}`). It is placed from this device's own camera cutout and logical grid, so it lines up with the hardware on every variant. See [Status bar](/docs/screen-content#status-bar). |
| `color` | `string` | `'#2b292c'` | Body color. Takes a colorway id from `GALAXY_TAB_COLORWAYS[variant]` (see [Colorways](#colorways)) or any CSS color. |
| `resolution` | `number` | per variant | Defaults to the variant's logical grid: 800×1280 (tabs11), 924×1480 (tabs11ultra). |

## Regions

One region: the screen (bare children). Use the explicit
`<GalaxyTabMockup.Screen>` slot when you want per-surface overrides -
`surfaceBackground`, `resolution`, `surfaceStyle`. The same slot exists on
the bare `<GalaxyTab>`.

## Colorways

Pass a colorway id from `GALAXY_TAB_COLORWAYS[variant]` for that model's
retail finish, or any CSS color for a custom one. An id wins over a CSS color
of the same name - pass hex if you mean the CSS one.

| Model | Colorway ids (body color) |
| --- | --- |
| Galaxy Tab S11, Galaxy Tab S11 Ultra (`tabs11`, `tabs11ultra`) | `gray` (`#63656a`), `silver` (`#d3d4d8`) |

## This model

### Galaxy Tab S11

The default model: an 11″ AMOLED (800×1280) under a uniform bezel with no
notch - the front camera sits in the landscape-top bezel - in a 5.5 mm body
with a single rear camera ring and flash, the S Pen mount on the long side and
USB-C on the portrait-top edge. In Silver.
