`<Laptop>` and `<LaptopMockup>` render an Apple-style laptop: unibody deck
with the real 78-key Magic Keyboard layout (printed legends, instanced
keycaps, set in a well milled into the deck at Apple's pitch and position),
trackpad, hinge band, ports, and the display. Five variants at true
relative size: MacBook Air 13" / 15" and MacBook Pro 14" / 16" (M5), with
their notched panels - the Pro adds its full port array (MagSafe, 2×
Thunderbolt and headphone jack left; HDMI, Thunderbolt and SDXC right), the
black well floor the Air does without, perforated speaker strips flanking
the keyboard, bigger feet, the lid badge and the embossed underside wordmark -
and the MacBook Neo 13", the entry model with a notchless panel, the camera
in the bezel above it, colour-matched keycaps, two USB-C ports and no MagSafe.

The window on screen is real DOM, not a texture - drag anywhere to orbit. The
keyboard and palm rest occlude it per-pixel, so the screen's reflection ends
exactly where the hardware begins.

## Props

Beyond the [shared screen props](/docs/screen-content) and, on the mockup, the
[shared mockup props](/docs/api):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'air13' \| 'air15' \| 'pro14' \| 'pro16' \| 'neo13'` | `'air13'` | MacBook Air 13"/15", MacBook Pro 14"/16" or MacBook Neo 13" - true relative sizes, per-model ports, feet, speaker grilles, and the notch (the Neo has none: its camera sits in the bezel). |
| `openAngle` | `number` | `110` | Lid angle in degrees between deck and screen (90 is upright). |
| `color` | `string` | `'#e3e4e6'` | Aluminum finish. Takes a colorway id from `LAPTOP_COLORWAYS[variant]` (see [Colorways](#colorways)) or any CSS color. |
| `resolution` | `number` | per variant | Virtual display width - each variant defaults to its real scaled desktop: 1280×832 (air13), 1440×932 (air15), 1512×982 (pro14), 1728×1117 (pro16), 1204×753 (neo13) - so desktop breakpoints apply. |

There is no `orientation` prop: a laptop has one pose.

## Regions

One region: the screen (bare children). Use the explicit
`<LaptopMockup.Screen>` slot when you want per-surface overrides -
`surfaceBackground`, `resolution`, `surfaceStyle`. The same slot exists on
the bare `<Laptop>`.

## Colorways

Pass a colorway id from `LAPTOP_COLORWAYS[variant]` for that model's retail
finish, or any CSS color for a custom one. An id wins over a CSS color of the
same name - pass hex if you mean the CSS one.

| Model | Colorway ids (body color) |
| --- | --- |
| MacBook Air 13″, MacBook Air 15″ (`air13`, `air15`) | `silver` (`#e3e4e6`), `starlight` (`#e8e0d4`), `midnight` (`#2e3642`), `skyblue` (`#aec6d9`) |
| MacBook Pro 14″, MacBook Pro 16″ (`pro14`, `pro16`) | `spaceblack` (`#4a484b`), `silver` (`#e3e4e6`) |
| MacBook Neo 13″ (`neo13`) | `silver` (`#e3e4e6`), `blush` (`#e9cfd0`), `citrus` (`#dedb92`), `indigo` (`#505b73`) |
