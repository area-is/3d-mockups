`<Laptop>` and `<LaptopMockup>` render an Apple-style laptop: unibody deck
with the real 78-key Magic Keyboard layout (printed legends, instanced
keycaps), trackpad, hinge band, ports, and a notched display. Four variants at
true relative size: MacBook Air 13" / 15" and MacBook Pro 14" / 16" (M5) - the
Pro adds its scan-accurate port array (MagSafe, 2× Thunderbolt and headphone
jack left; HDMI, Thunderbolt and SDXC right), the black keyboard tray the Air
does without, perforated speaker strips flanking the keyboard, bigger feet,
the lid badge and the embossed underside wordmark.

The window on screen is real DOM, not a texture - drag anywhere to orbit. The
keyboard and palm rest occlude it per-pixel, so the screen's reflection ends
exactly where the hardware begins.

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'air13' \| 'air15' \| 'pro14' \| 'pro16'` | `'air13'` | MacBook Air 13"/15" or MacBook Pro 14"/16" - true relative sizes, per-model ports, feet, speaker grilles and notch. |
| `color` | `string` | `'#e3e4e6'` | Aluminum finish. Takes a retail colorway id from `LAPTOP_COLORWAYS` - Airs `silver`, `starlight`, `midnight`, `skyblue`; Pros `spaceblack`, `silver` - or any CSS color. |
| `openAngle` | `number` | `110` | Lid angle in degrees between deck and screen (90 is upright). |
| `resolution` | `number` | per variant | Virtual display width - each variant defaults to its real scaled desktop: 1280×832 (air13), 1440×932 (air15), 1512×982 (pro14), 1728×1117 (pro16) - so desktop breakpoints apply. |

There is no `orientation` prop; laptops only have one pose.
