`<Magazine>` and `<MagazineMockup>` render a 216×279 mm letter-trim,
perfect-bound magazine: a thin page block with crisp trimmed paper edges on
the three open sides, the cover stock wrapping the bound spine, and live
480×620 DOM front and back covers. The spine itself is a live surface too -
the narrow strip where magazines carry the title and issue number, reading
top-to-bottom like a shelf spine. The stock is matte paper by default -
flat under any light; opt into `glossy` for the coated look with a soft
diagonal sheen.

Real editorial CSS lays out exactly as it would in a browser at 480×620.

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `{ width?, height?, thickness? }` | `216×279×6` | Physical trim in mm - e.g. `{ width: 210, height: 297 }` for A4, `{ thickness: 12 }` for a thick issue. |
| `pageColor` | `string` | `'#fbfaf7'` | Paper color of the trimmed page edges. |
| `backColor` | `string` | `'#e9e7e2'` | Back cover and spine-wrap color. |
| `glossy` | `boolean` | `false` | Coated gloss stock: a soft diagonal sheen over the cover art and a clearcoat on the spine and back. Off = matte paper. |
| `surfaceBackground` | `string` | `'#ffffff'` | CSS background behind your cover content. |
| `resolution` | `number` | `480` | Virtual cover width in CSS px; height follows the trim aspect. |

## Regions

| Slot | Surface |
| --- | --- |
| `<MagazineMockup.Cover>` | Front cover (bare children). |
| `<MagazineMockup.Back>` | Back cover - full bleed, same stock finish. |
| `<MagazineMockup.Spine>` | Spine strip - content is rotated to read top-to-bottom like a real shelf spine (your DOM's left edge lands at the spine's top), and renders at 3× the cover dpi so small type stays crisp. |

Every slot takes per-surface overrides - `surfaceBackground`,
`resolution`, `surfaceStyle` - over the mockup-level defaults. The
same slots exist on the bare `<Magazine>`.

## More examples

### The back-cover ad

Magazines sell their back page - `<MagazineMockup.Back>` prints it, full
bleed.

<ObjectDemo demo="magazine-back" />

```tsx
<MagazineMockup autoRotate>
  <YourCoverArt />
  <MagazineMockup.Back>
    <BackCoverAd />
  </MagazineMockup.Back>
</MagazineMockup>
```

### The spine

Title and issue number on the bound edge - `<MagazineMockup.Spine>` prints
the strip, reading top-to-bottom like a real shelf spine.

<ObjectDemo demo="magazine-spine" />

```tsx
<MagazineMockup rotation={[0, 0.95, 0]}>
  <YourCoverArt />
  <MagazineMockup.Spine>
    <YourSpineStrip />
  </MagazineMockup.Spine>
  <MagazineMockup.Back>
    <BackCoverAd />
  </MagazineMockup.Back>
</MagazineMockup>
```

### Matching the stock to the issue

`backColor` paints the back cover and the perfect-bound spine wrap;
`pageColor` tints the trimmed page edges. Dark issues look best when all
three agree.

<MockupExplorer
  component="MagazineMockup"
  props={{ pageColor: '#efeadd', backColor: '#101319', float: true, rotation: [0, 0.3, 0] }}
/>
