`<SemiTrailer>` and `<SemiTrailerMockup>` render a US-standard 53 ft dry van
parked on its landing gear: smooth wrap-ready sides, tandem rear axles with
dual wheels and mudflaps, side skirts, ICC bumper, lock-rod rear doors, amber
front markers and DOT reflective tape along the bottom rails. The biggest
canvas in the library - both 15.2×2.6 m sides plus the rear doors are live.

## `<SemiTrailer>` vs `<SemiTrailerMockup>`

<BareVsMockup object="SemiTrailer" kind="semiTrailer" slot="CurbSide" />

```tsx
import { MockupCanvas, SemiTrailer, SemiTrailerMockup } from 'area-3d-mockups'

// The one-liner: its own canvas, with lighting, a ground shadow, drag-to-orbit
// controls and a camera already framed on the object.
<SemiTrailerMockup float style={{ height: 520 }}>
  <YourApp />
</SemiTrailerMockup>

// The same model with no stage of its own. Inside a canvas you arrange
// yourself it can be posed, animated, lit and joined by anything else.
<MockupCanvas>
  <SemiTrailer rotation={[0, 0.4, 0]}>
    <YourApp />
  </SemiTrailer>
</MockupCanvas>
```

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `color` | `string` | `'#eef0f2'` | Box paint. Wrap trailers are usually white. |
| `skirtColor` | `string` | matches `color` | Side-skirt paint - the thin aero panels under the box. |
| `surfaceBackground` | `string` | `'#ffffff'` | CSS background behind your wrap content. |
| `resolution` | `number` | `1100` | Virtual side panel width in CSS px; the rear shares its dpi. |

## Regions

| Slot | Surface |
| --- | --- |
| `<SemiTrailerMockup.CurbSide>` | Curb-side (+Z) wrap panel (bare children). |
| `<SemiTrailerMockup.StreetSide>` | Street-side (−Z) wrap panel. |
| `<SemiTrailerMockup.Rear>` | Rear-door panel - the lock rods overlay it like real hardware. |

Every slot takes per-surface overrides - `surfaceBackground`,
`resolution`, `surfaceStyle` - over the mockup-level defaults. The
same slots exist on the bare `<SemiTrailer>`.

The road sits `SEMI_TRAILER.groundY` below the origin - the mockup grounds
the shadow there automatically.
