`<DOOHTotem>` and `<DOOHTotemMockup>` render a digital out-of-home street
totem (digital 6-sheet class): a rounded street-furniture enclosure on a low
plinth with dark glass on both faces, and a live portrait 540×960 display -
the digital sibling of the [billboard](/docs/api/billboard) and
[bus shelter](/docs/api/bus-shelter).

## `<DOOHTotem>` vs `<DOOHTotemMockup>`

<BareVsMockup object="DOOHTotem" kind="doohTotem" slot="Front" />

```tsx
import { MockupCanvas, DOOHTotem, DOOHTotemMockup } from 'area-3d-mockups'

// The one-liner: its own canvas, with lighting, a ground shadow, drag-to-orbit
// controls and a camera already framed on the object.
<DOOHTotemMockup float style={{ height: 520 }}>
  <YourApp />
</DOOHTotemMockup>

// The same model with no stage of its own. Inside a canvas you arrange
// yourself it can be posed, animated, lit and joined by anything else.
<MockupCanvas>
  <DOOHTotem rotation={[0, 0.4, 0]}>
    <YourApp />
  </DOOHTotem>
</MockupCanvas>
```

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `{ width?, height? }` | `1300×2800` | Physical enclosure in mm - e.g. `{ width: 1100, height: 2500 }` for a slimmer kiosk. The glass and display scale with the cabinet. |
| `color` | `string` | `'#2f333a'` | Enclosure colorway. |
| `resolution` | `number` | `540` | Virtual display width; 540 gives 540×960 (a 1080×1920 grid at 2x). |

## Regions

| Slot | Surface |
| --- | --- |
| `<DOOHTotemMockup.Front>` | Front display (bare children). |
| `<DOOHTotemMockup.Back>` | Back display - real totems are double-sided. |

Every slot takes per-surface overrides - `surfaceBackground`,
`resolution`, `surfaceStyle` - over the mockup-level defaults. The
same slots exist on the bare `<DOOHTotem>`.
