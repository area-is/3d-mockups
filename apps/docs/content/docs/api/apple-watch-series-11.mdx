`<AppleWatch>` and `<AppleWatchMockup>` render an Apple Watch Series 11, 46 mm,
wearing a real wristband on an invisible wrist directly behind the case - the
band sliding into the slots machined in the case edges, exactly how worn-band
product photos pose it.

The case is a squircle with the gear-toothed knurled Digital Crown, the flush
side button in its machined recess, a drilled mic hole and a machined speaker
slot on the left edge, under an edge-to-edge crystal over the live 208×248
rounded-rect face. The back carries its real sensor cluster: an optical heart
sensor behind a round crystal ringed by the ECG electrode, sunk flush into a
body-colour aluminium plate with the charging-coil ring engraved outside it.

Its band is the **Solo Loop**: one continuous stretchy band, sized to the wrist
rather than adjusted, so there is no closure, no adjustment holes and no
hardware anywhere on it - it just flares into the lug slots at both ends. That
is why this component has no `bandOpen` prop; nothing on it unfastens. For a
band that lays open, see [Galaxy Watch](/docs/api/galaxy-watch-8).

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'series11'` | `'series11'` | Which Apple Watch to render. |
| `color` | `string` | `'#1c1d21'` | Aluminium case. Takes a retail colorway id from `APPLE_WATCH_COLORWAYS` (`jetblack`, `spacegray`, `rosegold`, `silver`) or any CSS color. |
| `bandColor` | `string` | `'#2a2c31'` | Solo Loop colorway. |
| `resolution` | `number` | `208` | Virtual display width - 208 is the watch's own point grid, so watchOS-sized layouts apply. |

There is no `orientation` prop, and no `bandOpen`.
