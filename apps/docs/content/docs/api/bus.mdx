---
title: Bus (city transit)
description: A 40 ft low-floor transit bus with live ad panels, full-wrap coverage and an LED destination sign.
---

`<Bus>` and `<BusMockup>` render a generic 40 ft / 12 m low-floor city
transit bus (Xcelsior/LFS/Citaro-class silhouette, no brand): a one-box
shell with no hood, a lightly-raked two-piece windshield under the dark sign
fascia, a window band covering nearly half the body height, the driver's
window behind the street-side A-pillar, two full-glass curb-side doors, flat
roof with HVAC pod, stacked round taillights and rear louvers. Live
surfaces:

- the classic **king-size ad panel** (30"×144") between the wheels - or the
  **entire sides and tail** with `coverage="full"`, transit-wrap style, and
- optionally the **LED destination sign** above the windshield via
  `<Bus.DestinationSign>`.

Give `<Bus.DestinationSign>` a plain string and the built-in dot-matrix LED
renderer takes over - it scrolls as a marquee when the text overflows. Pass
an array of strings and the sign flips between them like a real alternating
destination sign. Any React node still works for full custom control.

<ObjectDemo demo="bus-basic" checker />

```tsx
<BusMockup rotation={[0, 0.35, 0]}>
  <YourCreative />
  <BusMockup.DestinationSign>{['42 DOWNTOWN', 'VIA 5TH AVE']}</BusMockup.DestinationSign>
</BusMockup>
```

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `color` | `string` | `'#eef0f2'` | Body paint. Transit fleets are usually white or silver. |
| `surfaceBackground` | `string` | `'#ffffff'` | CSS background behind your ad content. |
| `coverage` | `'panel' \| 'full' \| 'perforated'` | `'panel'` | How much of the bus the live surfaces cover. `'full'` turns the entire side elevations and the tail live, carving the passenger glass out so it stays visible; `'perforated'` runs the same wrap OVER that glass as perforated window film. Doors and the driver's window always stay clear. |
| `resolution` | `number` | `960` panel · `1920` full | Virtual side-surface width in CSS px; the rear surface shares its dpi. |

## Regions

| Slot | Surface |
| --- | --- |
| `<BusMockup.CurbSide>` | Curb-side (+Z) ad surface - the king-size panel, or the whole side with `coverage="full"` (bare children). |
| `<BusMockup.StreetSide>` | Street-side (−Z) ad surface. |
| `<BusMockup.Rear>` | Rear surface: the 21"×70" tail ad, or the whole tail with `coverage="full"`. |
| `<BusMockup.DestinationSign>` | Live LED sign above the windshield. A string gets the built-in dot-matrix renderer (marquee when it overflows), an array of strings flips between them like an alternating sign; a node renders as-is. |

Every slot takes per-surface overrides - `surfaceBackground`,
`resolution`, `surfaceStyle` - over the mockup-level defaults. The
same slots exist on the bare `<Bus>`.

## More examples

### The full transit wrap

`coverage="full"` stretches the live panels across the whole side
elevation (skirts to roofline, tail to nose) and the whole tail. A CSS `clip-path`
(computed from the same dimension spec the geometry is built from) carves
out the body outline, wheel arches, door leaves, taillights - and the
driver's window, which vinyl never covers - and the sides composite
per-pixel against a depth occluder shaped like that clip, so the proud
door mirrors draw over the livery instead of being covered by it. Graphics
DO run over the passenger windows, exactly like a real perforated-film
wrap.

<ObjectDemo demo="bus-full" />

```tsx
<BusMockup coverage="full" rotation={[0, 0.42, 0]}>
  <FullLivery />
  <BusMockup.StreetSide><FullLivery /></BusMockup.StreetSide>
  <BusMockup.Rear><TailLivery /></BusMockup.Rear>
  <BusMockup.DestinationSign>{['12 EASTBROOK', 'VIA HARBOR FRONT']}</BusMockup.DestinationSign>
</BusMockup>
```

### Full wrap with the glass kept clear

`coverage="full"` layers the graphics UNDER the glass: the passenger window
band and the rear window are carved out of the wrap, so the 3D glass shows
through - the classic partial-wrap look. Each rear lamp is carved out
individually either way, so the tail graphic runs right up to the light
collars.

<ObjectDemo demo="bus-full-clear" />

```tsx
<BusMockup coverage="full">
  <Livery />
  <BusMockup.StreetSide><Livery /></BusMockup.StreetSide>
  <BusMockup.Rear><TailLivery /></BusMockup.Rear>
</BusMockup>
```

### Rear three-quarter with the tail ad

Rear window, stacked brake/turn lamps, engine louvers - and the 21"×70"
tail ad between them. A custom node as the destination sign, for when the
built-in LED look isn't enough.

<ObjectDemo demo="bus-rear" />

```tsx
<BusMockup rotation={[0, 2.35, 0]}>
  <Creative />
  <BusMockup.StreetSide><Creative /></BusMockup.StreetSide>
  <BusMockup.Rear><TailAd /></BusMockup.Rear>
  <BusMockup.DestinationSign><Route42Marquee /></BusMockup.DestinationSign>
</BusMockup>
```

### A liveried fleet bus

`color` paints the shell; match `surfaceBackground` to the creative for a
wrapped look. A single long string on the sign auto-scrolls.

<ObjectDemo demo="bus-livery" />

```tsx
<BusMockup color="#1d4433" surfaceBackground="#f4c534" autoRotate>
  <YourCreative />
  <BusMockup.DestinationSign>42 GREENWAY · NEXT STOP CANAL ST</BusMockup.DestinationSign>
</BusMockup>
```
