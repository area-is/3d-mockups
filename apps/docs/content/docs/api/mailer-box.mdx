---
title: Mailer box
description: A corrugated shipper with every panel printable under real packing tape.
---

`<MailerBox>` and `<MailerBoxMockup>` render a closed corrugated shipping
box (350×120×250 mm): kraft stock, the flaps hinged on the long walls
meeting along the width, a visible flap gap under the translucent
packing-tape band that wraps over the top and down both short ends, and the
manufacturer's glued lap seam on one corner. Every panel is live — top,
front, back, both ends and the bottom — and the tape rides *over* your
print via a DOM overlay, exactly like tape over a printed box. Pass `size` (in millimeters) for a shipper of
any other dimensions.

<ObjectDemo demo="mailer-basic" checker />

```tsx
<MailerBoxMockup rotation={[0, 0.5, 0]}>
  <YourTopPanel />
  <MailerBoxMockup.Front><YourFrontPanel /></MailerBoxMockup.Front>
</MailerBoxMockup>
```

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `{ width, height, depth }` | `350×120×250` | Real size in **millimeters**. The longest edge normalizes to the stage, so any size fills the camera at true proportions. |
| `color` | `string` | `'#b5915f'` | Corrugated stock. Kraft by default; try white or a brand dip. |
| `tapeColor` | `string` | `'rgba(168, 127, 79, 0.82)'` | Packing tape color. |
| `surfaceBackground` | `string` | `'#ffffff'` | CSS background behind each printed panel. |
| `resolution` | `number` | `520` | Virtual top panel width in CSS px; other panels share its dpi. |

## Regions

| Slot | Panel |
| --- | --- |
| `<MailerBoxMockup.Top>` | Top panel — the hero face, with the tape riding over it (bare children). |
| `<MailerBoxMockup.Front>` | Front (long) panel. |
| `<MailerBoxMockup.Back>` | Back (long) panel. |
| `<MailerBoxMockup.Right>` | Right end panel — the wrapped tape rides over it. |
| `<MailerBoxMockup.Left>` | Left end panel — the wrapped tape rides over it. |
| `<MailerBoxMockup.Bottom>` | Bottom panel, reading from the front when flipped. |

Every slot takes per-surface overrides — `background`, `resolution`,
`allowInput`, `dragToRotate`, `style` — over the mockup-level defaults. The
same slots exist on the bare `<MailerBox>`.

## More examples

### Every panel printed

Handling marks on both ends, the recycled stamp underneath, brand panels
front and back — the box reads as a designed shipper from any angle.

<ObjectDemo demo="mailer-full" />

```tsx
<MailerBoxMockup autoRotate>
  <YourTopPanel />
  <MailerBoxMockup.Front><BrandPanel /></MailerBoxMockup.Front>
  <MailerBoxMockup.Back><BrandPanel /></MailerBoxMockup.Back>
  <MailerBoxMockup.Right><HandlingMarks /></MailerBoxMockup.Right>
  <MailerBoxMockup.Left><HandlingMarks /></MailerBoxMockup.Left>
  <MailerBoxMockup.Bottom><RecycledStamp /></MailerBoxMockup.Bottom>
</MailerBoxMockup>
```

### Unprinted white shipper

Leave `children` off and the box renders in its unprinted state — flap slabs
and a skewed 4×6 shipping label instead of a live top panel.

<ObjectDemo demo="mailer-blank" />

```tsx
<MailerBoxMockup
  float
  color="#e8e4dd"
  tapeColor="rgba(210, 205, 196, 0.9)"
  camera={{ position: [0, 3.2, 6.6], fov: 40 }}
  rotation={[0, -0.4, 0]}
/>
```
