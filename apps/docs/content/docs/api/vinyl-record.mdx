---
title: Vinyl record
description: A 12-inch LP half-out of its sleeve, with live cover, back and disc label.
---

`<VinylRecord>` and `<VinylRecordMockup>` render a 12" LP: a 313 mm square
hollow jacket with live front (and optional back) cover art, and a glossy
302 mm disc, grooved on both sides, sliding out of the sleeve far enough to
clear the whole label — concentric track-gap sheen rings, dead-wax annulus,
spindle hole, and the 100 mm center label as a live **circular** DOM area.

<ObjectDemo demo="vinyl-basic" checker />

```tsx
<VinylRecordMockup rotation={[0, -0.2, 0]}>
  <CoverArt />
  <VinylRecordMockup.Label>
    <Label />
  </VinylRecordMockup.Label>
</VinylRecordMockup>
```

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `vinylColor` | `string` | `'#0b0b0d'` | Disc color. Classic black; try pressing colors. |
| `color` | `string` | `'#f2efe8'` | Jacket stock (edges and unprinted faces). |
| `surfaceBackground` | `string` | `'#ffffff'` | CSS background behind cover, back and label. |
| `resolution` | `number` | `520` | Virtual cover width in CSS px; the label shares its dpi. |

## Regions

| Slot | Surface |
| --- | --- |
| `<VinylRecordMockup.Cover>` | Front cover art (bare children). |
| `<VinylRecordMockup.Back>` | Back cover — the tracklist side of the jacket. |
| `<VinylRecordMockup.Label>` | Side-A center label — a live circular DOM area. |
| `<VinylRecordMockup.BackLabel>` | Side-B center label on the disc's other face. |

Every slot takes per-surface overrides — `background`, `resolution`,
`style` — over the mockup-level defaults. The
same slots exist on the bare `<VinylRecord>`.

## Mockup-able areas

## More examples

### Back cover and side B

`<VinylRecordMockup.Back>` prints the tracklist side of the jacket and
`<VinylRecordMockup.BackLabel>` the disc's side-B label, so the record reads
right from behind too.

<ObjectDemo demo="vinyl-full" />

```tsx
<VinylRecordMockup autoRotate>
  <CoverArt />
  <VinylRecordMockup.Back>
    <Tracklist />
  </VinylRecordMockup.Back>
  <VinylRecordMockup.Label>
    <SideA />
  </VinylRecordMockup.Label>
  <VinylRecordMockup.BackLabel>
    <SideB />
  </VinylRecordMockup.BackLabel>
</VinylRecordMockup>
```
