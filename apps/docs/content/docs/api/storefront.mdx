title: Storefront
description: A free-standing corner shop with live surfaces on all four elevations.
---

`<Storefront>` and `<StorefrontMockup>` render a free-standing single-story
corner shop: four glazed shopfront elevations under a capped flat roof,
the parapet sitting just above the cornice so the painted composition IS
the whole building. The front is the classic high-street shopfront -
painted timber surround with cornice and pilasters, a 600 mm stall riser,
big display glazing with a mullion, a glazed door on the right. The other
three elevations repeat the same composition without the door - windows
only - and each carries its own live fascia sign. Every big pane is a
mockup surface too: both front display bays, the glazed door leaf and the
wide center pane of each other elevation - each its own slot. Ten live
surfaces in all (the roof stays hardware).

## `<Storefront>` vs `<StorefrontMockup>`

<BareVsMockup object="Storefront" kind="storefront" slot="Fascia" />

```tsx
import { MockupCanvas, Storefront, StorefrontMockup } from 'area-3d-mockups'

// The one-liner: its own canvas, with lighting, a ground shadow, drag-to-orbit
// controls and a camera already framed on the object.
<StorefrontMockup float style={{ height: 520 }}>
  <YourApp />
</StorefrontMockup>

// The same model with no stage of its own. Inside a canvas you arrange
// yourself it can be posed, animated, lit and joined by anything else.
<MockupCanvas>
  <Storefront rotation={[0, 0.4, 0]}>
    <YourApp />
  </Storefront>
</MockupCanvas>
```

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `color` | `string` | `'#2e4638'` | Shopfront paint: fascia surrounds, frames, door, stall risers. |
| `windowColor` | `string` | `'#5a6d75'` | Glazing color - every display pane, the transom lights and the door leaf. Tints the reflection rather than painting the pane flat, so the glass keeps its mirror finish. Try `'#6b5a44'` bronze, `'#4d6b60'` green, or something darker for a shop that reads as closed. |
| `surfaceBackground` | `string` | `'#ffffff'` | CSS background behind sign and poster content. |
| `resolution` | `number` | `800` | Virtual fascia sign width in CSS px. Window panes use fixed widths (~420–480 px); override per pane with each slot's `resolution`. |

## Regions

| Slot | Surface |
| --- | --- |
| `<StorefrontMockup.Fascia>` | Front fascia sign (bare children). |
| `<StorefrontMockup.FrontLeft>` | Front display bay left of the mullion. |
| `<StorefrontMockup.FrontRight>` | Front display bay right of the mullion. |
| `<StorefrontMockup.Door>` | Glazed door leaf. |
| `<StorefrontMockup.Left>` | Wide center pane of the left elevation (−X as you face the shop). |
| `<StorefrontMockup.Right>` | Wide center pane of the right elevation (+X). |
| `<StorefrontMockup.Rear>` | Wide center pane of the rear elevation (−Z). |
| `<StorefrontMockup.LeftSign>` | Fascia sign on the left elevation. |
| `<StorefrontMockup.RightSign>` | Fascia sign on the right elevation. |
| `<StorefrontMockup.RearSign>` | Fascia sign on the rear elevation. |

Every slot takes per-surface overrides - `surfaceBackground`,
`resolution`, `surfaceStyle` - over the mockup-level defaults. The
same slots exist on the bare `<Storefront>`.

The pavement sits `STOREFRONT.standHeight` below the origin - the mockup
grounds the shadow there automatically.
