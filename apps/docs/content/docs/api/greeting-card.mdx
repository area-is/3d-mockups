`<GreetingCard>` and `<GreetingCardMockup>` render a folded 5"×7" (A7) card
standing like a tent, fold toward the viewer: bare children fill the front
cover, `<GreetingCardMockup.Back>` the other outward face, and
`<GreetingCardMockup.InsideLeft>`/`<GreetingCardMockup.InsideRight>` print
the spread you see from behind. Each face gently shades into the crease, like
paper actually bowing.

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `openAngle` | `number` | `65` | Angle between the panels (display sweet spot is 60–75). |
| `color` | `string` | `'#f6f3ec'` | Card stock: edges and unprinted faces. |
| `surfaceBackground` | `string` | `'#ffffff'` | CSS background behind each printed face. |
| `resolution` | `number` | `380` | Virtual panel width in CSS px; height follows the A7 panel. |

## Regions

| Slot | Surface |
| --- | --- |
| `<GreetingCardMockup.Front>` | Front cover (bare children). |
| `<GreetingCardMockup.InsideLeft>` | Inside-left panel of the spread. |
| `<GreetingCardMockup.InsideRight>` | Inside-right panel of the spread. |
| `<GreetingCardMockup.Back>` | Back cover - the left outward face. |

Every slot takes per-surface overrides - `surfaceBackground`,
`resolution`, `surfaceStyle` - over the mockup-level defaults. The
same slots exist on the bare `<GreetingCard>`.
