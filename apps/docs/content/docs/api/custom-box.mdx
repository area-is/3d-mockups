---
title: Custom box
description: A rectangular box at any size you specify in millimeters, printable on all six faces.
---

`<CustomBox>` and `<CustomBoxMockup>` render a rectangular box at ANY size -
shipper, carton, counter display, crate. Pass real millimeters via `size`;
the longest edge auto-normalizes to the stage while the mm dimensions keep
the true proportions. All six faces are printable live DOM at one shared
dpi.

/>

## `<CustomBox>` vs `<CustomBoxMockup>`

<BareVsMockup object="CustomBox" kind="customBox" slot="Front" />

```tsx
import { MockupCanvas, CustomBox, CustomBoxMockup } from 'area-3d-mockups'

// The one-liner: its own canvas, with lighting, a ground shadow, drag-to-orbit
// controls and a camera already framed on the object.
<CustomBoxMockup float style={{ height: 520 }}>
  <YourApp />
</CustomBoxMockup>

// The same model with no stage of its own. Inside a canvas you arrange
// yourself it can be posed, animated, lit and joined by anything else.
<MockupCanvas>
  <CustomBox rotation={[0, 0.4, 0]}>
    <YourApp />
  </CustomBox>
</MockupCanvas>
```

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `{ width, height, depth }` | required | Box size in millimeters. |
| `color` | `string` | `'#e8e5df'` | Stock color for unprinted faces. |
| `surfaceBackground` | `string` | `'#ffffff'` | CSS background behind each printed face. |
| `resolution` | `number` | `560` | Virtual front face width in CSS px; all faces share its dpi. |

`customBoxScale(size)` is exported if you need the world-units-per-mm
factor.

## Regions

| Slot | Surface |
| --- | --- |
| `<CustomBoxMockup.Front>` | Front (+z) face (bare children). |
| `<CustomBoxMockup.Back>` | Back (−z) face. |
| `<CustomBoxMockup.Left>` | Left (−x) face. |
| `<CustomBoxMockup.Right>` | Right (+x) face. |
| `<CustomBoxMockup.Top>` | Top face. |
| `<CustomBoxMockup.Bottom>` | Bottom face. |

Every slot takes per-surface overrides - `surfaceBackground`,
`resolution`, `surfaceStyle` - over the mockup-level defaults. The
same slots exist on the bare `<CustomBox>`.
