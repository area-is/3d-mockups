`<RollupBanner>` and `<RollupBannerMockup>` render the trade-show standard
850×2000 mm retractable banner: an aluminum cassette base with rounded ends,
end caps and swivel feet, the graphic rising out of the cassette slot to a
slim top clamp rail, with the support pole hidden behind. The graphic is a
live 420×988 DOM surface. The mockup grounds the cassette on a virtual
floor.

## `<RollupBanner>` vs `<RollupBannerMockup>`

<BareVsMockup object="RollupBanner" kind="rollupBanner" slot="Banner" />

```tsx
import { MockupCanvas, RollupBanner, RollupBannerMockup } from 'area-3d-mockups'

// The one-liner: its own canvas, with lighting, a ground shadow, drag-to-orbit
// controls and a camera already framed on the object.
<RollupBannerMockup float style={{ height: 520 }}>
  <YourApp />
</RollupBannerMockup>

// The same model with no stage of its own. Inside a canvas you arrange
// yourself it can be posed, animated, lit and joined by anything else.
<MockupCanvas>
  <RollupBanner rotation={[0, 0.4, 0]}>
    <YourApp />
  </RollupBanner>
</MockupCanvas>
```

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `{ width?, height? }` | `850×2000` | Physical graphic in mm - e.g. `{ width: 1000 }` for the wide stand. The cassette resizes with it. |
| `color` | `string` | `'#b9bdc4'` | Hardware color: cassette, feet, pole, top rail. |
| `surfaceBackground` | `string` | `'#ffffff'` | CSS background behind your graphic content. |
| `resolution` | `number` | `420` | Virtual graphic width in CSS px; height follows the 850×2000 sheet. |

## Regions

One region: the graphic (bare children). Use the explicit
`<RollupBannerMockup.Banner>` slot when you want per-surface overrides -
`surfaceBackground`, `resolution`, `surfaceStyle`.
