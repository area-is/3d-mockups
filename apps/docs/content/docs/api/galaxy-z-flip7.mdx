`<Flip>` renders a Galaxy Z Flip - the Z Flip 7 or Z Flip 8, chosen with
`variant`; `<FlipMockup>` is the all-in-one version. One device, two form
factors: **open** (default) fills your content onto the tall main display, and
**closed** (`openAngle={false}`) folds to the compact square whose front is
nearly all cover screen - with the two separately protruding lens rings and
flash sitting on the glass (no plate joins them, matching the retail
hardware), and the hinge band (complete with its engraved wordmark) capping
the bottom. Detail geometry (button pills, lens rings, ports, seams) is built
from the Flip 7's published specifications and product photography; the Flip 8
carries the same details on its fractionally larger, thinner body.

To render this model, pass `variant="flip7"`.

```tsx
import { MockupCanvas, Flip, FlipMockup } from 'react-3d-mockups'

// The one-liner: its own canvas, with lighting, a ground shadow, drag-to-orbit
// controls and a camera already framed on the object.
<FlipMockup variant="flip7" float style={{ height: 520 }}>
  <YourApp />
</FlipMockup>

// The same model with no stage of its own. Inside a canvas you arrange
// yourself it can be posed, animated, lit and joined by anything else.
<MockupCanvas>
  <Flip variant="flip7" rotation={[0, 0.4, 0]}>
    <YourApp />
  </Flip>
</MockupCanvas>
```

## Props

Beyond the [shared screen props](/docs/screen-content) and, on the mockup, the
[shared mockup props](/docs/api):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'flip7' \| 'flip8'` | `'flip7'` | Which Galaxy Z Flip to render. The Flip 8 is a hair bigger and thinner, its main display grown to 6.9″ on the same panel grid; the cover screen is unchanged. |
| `openAngle` | `boolean \| number` | `true` | How far the clamshell is open. `true` is the unfolded tall phone (content on the main display), `false` the folded compact (content on the nearly square cover display, lens rings overlaid like cutouts). A number is degrees (0 = shut, 180 = flat) and renders the real Flex Mode pose: the lower half holds still and the cover half swings open about the crease, the Armor FlexHinge, while its glossy spine band (with the SAMSUNG engraving) rolls into the gap, and your content bends across the fold on two composited planes. The pose is continuous: every angle renders its own pose, and only the extremes hand over to the dedicated folded (~0°) and flat (180°) poses, which draw the crease as one seamless screen. The crease is the one line that never moves, so the open phone is centred on it and the folded one hangs below it, hinge up: upside down from the way a shut Flip is usually held. For that view, turn it a half-turn about z (`rotation={[0, 0, Math.PI]}`) and lower it by its folded height. |
| `orientation` | `'portrait' \| 'landscape'` | `'portrait'` | Landscape lays the device on its side and swaps the virtual display with upright content. |
| `statusBar` | `boolean \| StatusBarOption` | `false` | Draw the system status bar across the top of the screen. `true` gives the platform's defaults - One UI's, on the main display; the cover screen has its own clock and no status bar, so it draws none; an object sets the clock, the meters and the ink (`{{ time: '14:05', battery: 0.42, batteryPercent: true, color: '#1c1c1e' }}`). It is placed from this device's own camera cutout and logical grid, so it lines up with the hardware on every variant. See [Status bar](/docs/screen-content#status-bar). |
| `color` | `string` | `'#22252b'` | Back glass / cover. Takes a colorway id from `FLIP_COLORWAYS[variant]` (see [Colorways](#colorways)), which brings that model's frame and hinge band with it, or any CSS color - the metal is then derived from it. |
| `resolution` | `number` | per state | CSS pixel width of the active display; height follows the panel aspect. |
| `coverScreenUntil` | `number` | `30` | The hinge angle, in degrees, up to which the cover screen stays lit as the device opens; above it your content moves to the main display, so one of the two is lit at every angle, as on the hardware. `30` is where Android's reference foldable swaps; `90` keeps the cover on through the half-open tent pose, `0` swaps the moment the hinge moves. |

## The two states

The active display is whichever screen is lit, so your content maps onto the
cover screen from shut until the hinge passes `coverScreenUntil` (30° by
default) and the main display after it. Folded, the cover screen wraps around
the cameras exactly like the real FlexWindow:

## Any angle in between

`openAngle` takes a number of degrees to pose the phone at any openness - the classic half-open
Flex Mode stance, with the hinge spine rolling into the fold and your content
bending across it:

<MockupExplorer
  component="FlipMockup"
  variant="flip7"
  props={{ openAngle: 100, color: '#47536b', rotation: [0, -0.25, 0] }}
/>

Between open and closed, once the main display is lit (past
`coverScreenUntil`), each half of it is its own screen, so your screen content
is mounted once per half: effects, state and video run twice. Fully open,
shut, or while the cover screen is lit, it is mounted once. Each half lays
the content out at the whole display's size and shows its own part of it, so
`useSurface()` reports the whole display in both halves - the same numbers as
open flat.

## Regions

One region: the screen (bare children). `Screen` follows whichever display is
lit - the cover screen from shut until the hinge passes `coverScreenUntil`,
the main display after it. Use the explicit `<FlipMockup.Screen>` slot when
you want per-surface overrides - `surfaceBackground`, `resolution`,
`surfaceStyle`. The same slot exists on the bare `<Flip>`.

## Colorways

Pass a colorway id from `FLIP_COLORWAYS[variant]` for that model's retail
finish; it brings the matching frame and hinge band with it. Any CSS color
works for a custom finish, and the metal is then derived from it, so
`color="#bfe3d0"` needs nothing else. An id wins over a CSS color of the same
name - pass hex if you mean the CSS one.

| Model | Colorway ids (body color) |
| --- | --- |
| Galaxy Z Flip 7 (`flip7`) | `blueshadow` (`#47536b`), `jetblack` (`#17181c`), `coralred` (`#e5502e`), `mint` (`#cfe0d2`) |
| Galaxy Z Flip 8 (`flip8`) | `pink` (`#f2c6d3`), `cream` (`#ece5d8`), `graphite` (`#45474c`), `mint` (`#cfe0d2`) |
