`<ShoppingBag>` and `<ShoppingBagMockup>` render a standing retail carrier
(320×420×140 mm), hollow like the real thing: four walls and a floor around
an open rectangular mouth, side gussets creasing inward at the mouth and
folding flat toward the square block bottom (with the envelope fold visible
on the underside), and twisted-rope handles arcing over the rim to glued
reinforcement patches inside. The front and back faces are live, full bleed
to the top edge. Pass `size` (in millimeters) for a carrier of any other
dimensions.

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `{ width, height, depth }` | `320×420×140` | Real size in **millimeters**. The longest edge normalizes to the stage, so any size fills the camera at true proportions. |
| `color` | `string` | `'#c19a6b'` | Bag stock. Kraft by default; try gloss white or a brand dip. |
| `handleColor` | `string` | `'#7d6142'` | Rope handle color. |
| `surfaceBackground` | `string` | `'#ffffff'` | CSS background behind each printed face. |
| `resolution` | `number` | `460` | Virtual front face width in CSS px; height follows the bag. |

## Regions

| Slot | Surface |
| --- | --- |
| `<ShoppingBagMockup.Front>` | Front face (bare children). |
| `<ShoppingBagMockup.Back>` | Back face. |

Every slot takes per-surface overrides - `surfaceBackground`,
`resolution`, `surfaceStyle` - over the mockup-level defaults. The
same slots exist on the bare `<ShoppingBag>`.
