title: Brochure (tri-fold)
description: A standing letter Z-fold with three live panels, front and back.
---

`<Brochure>` and `<BrochureMockup>` render a US letter tri-fold standing in a
zig-zag (Z-fold) accordion. Each of the three 93×216 mm panels is its own
live 360×835 DOM surface - and the reverse faces can be printed too. Panels
shade gently toward the folds, like paper actually bowing.

Each panel has its own named slot, so content goes where the name says
regardless of what order you write them in. Each panel is independent live DOM.

<ObjectDemo demo="brochure-panels" checker />

```tsx
<BrochureMockup>
  <BrochureMockup.FrontLeft><Cover /></BrochureMockup.FrontLeft>
  <BrochureMockup.FrontCenter><Middle /></BrochureMockup.FrontCenter>
  <BrochureMockup.FrontRight><Visit /></BrochureMockup.FrontRight>
</BrochureMockup>
```

## Props

Beyond the [shared screen props](/docs/screen-content):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `{ width?, height? }` | `93×216` | One panel's physical size in mm - e.g. `{ width: 99, height: 210 }` for an A4 tri-fold. |
| `foldAngle` | `number` | `24` | Zig-zag fold angle in degrees. `0` lays the sheet out flat. |
| `color` | `string` | `'#f5f4f0'` | Stock color of unprinted faces and paper edges. |
| `surfaceBackground` | `string` | `'#ffffff'` | CSS background behind each panel's content. |
| `resolution` | `number` | `360` | Virtual width of one panel in CSS px; height follows the panel aspect. |

The fold keeps every panel centered on the group origin, so the brochure
orbits about its own visual center at any `foldAngle`.

## Regions

Six regions, one per printed panel:

| Slot | Surface |
| --- | --- |
| `<BrochureMockup.FrontLeft>` | Front face, left panel. Bare children are shorthand for this one. |
| `<BrochureMockup.FrontCenter>` | Front face, center panel. |
| `<BrochureMockup.FrontRight>` | Front face, right panel. |
| `<BrochureMockup.BackLeft>` | Reverse face, left panel. |
| `<BrochureMockup.BackCenter>` | Reverse face, center panel. |
| `<BrochureMockup.BackRight>` | Reverse face, right panel. |

**Left and right are always as the viewer of that face sees it.** Walk around
the brochure and `BackLeft` is the panel on your left - which is the reverse of
`FrontRight`. That is how a real tri-fold is imposed, and naming each panel for
its own face is what keeps the mirroring out of your head.

Order does not matter: write the slots in whatever order reads best, and
leaving one out is not a shift - it just shows bare `color` stock. Every slot
takes per-surface overrides - `surfaceBackground`, `resolution`,
`surfaceStyle` - over the mockup-level defaults. The same slots exist on the
bare `<Brochure>`.

## More examples

### All six surfaces printed

A real tri-fold prints on both sides of the sheet, and every face here is a
live surface. Spin the demo to read both sides.

<ObjectDemo demo="brochure-both-sides" />

```tsx
<BrochureMockup autoRotate>
  <BrochureMockup.FrontLeft><Cover /></BrochureMockup.FrontLeft>
  <BrochureMockup.FrontCenter><Trails /></BrochureMockup.FrontCenter>
  <BrochureMockup.FrontRight><Visit /></BrochureMockup.FrontRight>
  <BrochureMockup.BackLeft><Map /></BrochureMockup.BackLeft>
  <BrochureMockup.BackCenter><Hours /></BrochureMockup.BackCenter>
  <BrochureMockup.BackRight><Contact /></BrochureMockup.BackRight>
</BrochureMockup>
```

### Flat, before folding

`foldAngle={0}` lays the sheet out flat - useful for reviewing the design as
the full 11" spread it prints as.

<ObjectDemo demo="brochure-flat" />

```tsx
<BrochureMockup foldAngle={0}>
  <BrochureMockup.FrontLeft><Cover /></BrochureMockup.FrontLeft>
  <BrochureMockup.FrontCenter><Middle /></BrochureMockup.FrontCenter>
  <BrochureMockup.FrontRight><Visit /></BrochureMockup.FrontRight>
</BrochureMockup>
```

### One designed panel on bare stock

`children` is shorthand for `FrontLeft`; the rest show bare `color`
stock - a work-in-progress state that reads clearly in reviews.
